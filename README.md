# formrizk

Astro site with React islands for interactive sections and GSAP-driven motion.

## Getting Started

Run development server:

```bash
npm run dev
```

Default Astro preview/build commands:

```bash
npm run build
npm run preview
```

Main entrypoint lives at `src/pages/index.astro`. Interactive sections live in `src/components` and hydrate with `client:load`.
